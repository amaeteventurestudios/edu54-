# Services

Backend/adaptor services behind Umanah LabOS.

Planned domains:
- `ai/` — local model runtime/routing integration
- `learning/` — LMS/lesson/assignment adapters
- `coding/` — code runner/Jupyter integration
- `knowledge/` — local RAG/indexing/document services
- `telemetry/` — device/application health

Keep third-party components behind explicit integration boundaries.
