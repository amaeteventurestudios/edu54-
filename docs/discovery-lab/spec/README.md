# Discovery Lab development specifications

**Discovery Lab** is the approved name for a third educational experience within the existing provisionally named EDU54 platform. The parent brand may be renamed later.

Three connected experiences: K–12 Learning, University Learning, Discovery Lab. The new experience is a searchable library of interactive, primarily 2D/3D experiments with progressive depth, cross-course deep links, local search and a contextual AI Guide.

This package contains planning specifications, **not an audited implementation**. Current website and Ollama/Qwen implementation details need inspection in Claude's actual workspace. Previously researched GitHub repos are candidates, not preapproved assets.

Read in order: `CLAUDE.md`, then `docs/01` through `docs/09`. The project folder already set up by the founder is the authoritative destination. Do not overwrite existing project files without reviewing them first.
