# 06 Existing Ollama/Qwen AI plus offline predictive search

The founder reports the existing platform's AI agent **already connects to Ollama/Qwen on a friend's computer**. This is a requirement to preserve and reuse, **not independently verified implementation detail**. Claude must trace frontend → backend/model proxy → Ollama, establish the actual model and network transport through safe existing configuration, and test approved health and sample questions without changing the friend's computer. Never hardcode the host IP, expose keys in browser, or route student data to the remote host without privacy authorization.

Discovery Lab AI Guide should use the existing authorized model gateway for contextual explanations, guided questions, observation interpretation and learner support. Provide the **current experiment state, units, safe actions, source explanations** as context. LLM suggestions cannot execute arbitrary code: student confirms and adapter validates any simulation action. Use deterministic calculations to grade math or verify formulas. State uncertainty rather than inventing facts.

**Search must work without an LLM**: local index for subjects, collections, topics, experiences, tags and synonyms; predictive autocomplete/typeahead; instant results; typo tolerance; keyboard navigation; grouped cross-lab results; educational query synonyms (“gra” → graphing, gravity, granite). Optional natural-language intent mapping through local model, with deterministic fallback. Do not send every keystroke to Ollama; avoid unnecessary AI load.

When model unavailable, search and simulations keep working; show “AI Guide unavailable” and offline educational notes. Log service health, not student secrets. Benchmark 30 concurrent student requests on actual target hardware and verify privacy, latency, timeout, queueing, context size, injection handling and no-WAN operation. A remote computer reached through the internet is **not offline school inference**. School deployments must provide a LAN-accessible Ollama/Qwen server or an expressly approved different topology.
