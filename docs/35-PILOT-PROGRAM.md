# Pilot Program

## Goal

Validate learning value, operational reliability, teacher usability, and deployment economics in real environments before scaling.

## Pilot site profiles

- school classroom;
- library/community learning lab;
- nonprofit after-school program;
- potentially one research/college site for advanced feedback.

## Selection criteria

Committed teacher/site champion, basic LAN/power, willingness to provide structured feedback, ability to follow privacy/consent requirements, fit with target access barriers.

## Before any pilot with students

- Safeguarding reviewed by a counselor or child-safety professional; safety contact named at the site (`41`).
- Privacy documents and NDPA ready (`50`).
- Site network check done (`45`).
- Load test passed for the class size (`43`).
- Accessibility check passed (`49`).

## Pilot stages

1. Site discovery and requirements.
2. Agreement/policies.
3. Baseline survey/infrastructure check.
4. Appliance provisioning.
5. Teacher/admin onboarding.
6. Student launch.
7. Support + observation.
8. Midpoint review.
9. Final evaluation.
10. Product/operations revisions.

## Pilot success metrics

Reliability, weekly active learners, lesson completion, project completion, teacher adoption, support incidents, offline usability, AI response latency, satisfaction, learning evidence where appropriate.

## Do not overclaim

Prototype/pilot results are evidence for iteration, not proof of broad educational efficacy without appropriate study design.
